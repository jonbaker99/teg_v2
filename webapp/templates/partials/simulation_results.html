Each cell is that row player's handicap change, averaged over every order the changes could be applied in (Shapley), in percentage points for the column player.

How the split works (Shapley). One handicap change matters more or less depending on which other changes have already happened. Cutting one rival's handicap barely helps a player far off the pace, but helps a lot once they are in contention. So each change is tried in every possible order: first, last and everywhere in between. Its average effect across all those orders is its share. The shares always add up to the total change, so the whole swing is credited and nothing is counted twice.
