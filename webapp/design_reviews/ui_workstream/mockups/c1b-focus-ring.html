Focus ring — three alternatives

The bug being fixed: production's global :focus-visible outline and "selected" state are both green — keyboard focus is visually identical to selection. The owner's instinct is not to introduce another hue.

Tab into each column with the keyboard (or click, then Tab) to compare. Each column repeats the same two cases: a plain tab, and the selected segment of a measure control — the case that matters, because the selected segment is already green.

F1

Green ring, offset, halo

2px green outline, 3px offset, background-coloured halo pushes it fully clear of the box.

Plain tab
Selected segment (already green)
Focus ring is still green — on the selected segment it reads as "more selected," not "this is where the keyboard is."
F2

Green dashed

2px dashed green, offset 2px — texture differs from the solid underline used for selection.

Plain tab
Selected segment (already green)
More distinguishable than F1 thanks to the dash texture, but still the same hue as "selected" — weakest exactly where it matters most.
Recommend — F3

Ink solid, offset

2px --ink outline, offset 2px. No new hue — reuses the primary text token.

Plain tab
Selected segment (already green)
Ink reads clearly against the green-tinted selected segment in both modes — the one case F1/F2 fail. "Selection is green, focus is ink."
